# Actividad 7: Manipulación del DOM, Efectos y Eventos con jQuery

Repositorio estructurado para la actividad de **Programación para Internet** con todos los archivos en la raíz.

## Estructura

- `index.html`
- `styles.css`
- `app.js`
- `README.md`

## Funcionalidad

La página incluye:

- 1 encabezado (`<h1>`)
- 3 párrafos (`<p>`)
- 3 botones (`<button>`)

Con jQuery 3.7.1 se implementan eventos para:

- Ocultar párrafos (`fadeOut`)
- Mostrar párrafos (`fadeIn`)
- Destacar contenido (`toggleClass`)
