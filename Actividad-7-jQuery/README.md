# Actividad 7: Manipulación del DOM, Efectos y Eventos con jQuery

Proyecto correspondiente a la **Actividad 7** del curso *Programación para Internet* en la Universidad Anáhuac. Implementa una suite interactiva de telemetría táctica (Stark Industries) demostrando el uso de selectores jerárquicos, transiciones visuales, recorrido del DOM y control reactivo de eventos mediante la librería jQuery.
